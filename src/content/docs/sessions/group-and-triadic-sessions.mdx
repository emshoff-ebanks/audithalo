This guide covers supervision with more than one supervisee: triadic (you and two supervisees) and group. The logging and signing flow is the same as an individual session, with two differences: you add the other attendees, and every attendee must sign before the session seals.

## Session type: individual, triadic, or group

When you log or schedule a session, you choose its type:

- **Individual:** one supervisee.
- **Triadic:** you and two supervisees.
- **Group:** you and several supervisees.

For triadic and group, add the additional supervisees when you create the session.

1. Start the session from a supervisee's detail page or the calendar.
2. Choose triadic or group as the session type.
3. Add the additional supervisees as attendees.
4. Save or schedule the session.

## Every attendee signs

A group or triadic session seals only when all required signers have signed. You sign first, then each attending supervisee countersigns from their own dashboard.

- Each supervisee signs for their own participation.
- The evidence package is not sealed until the last required signature is recorded.
- Each supervisee sees the session in their own session log and progress.

> **Note:** Because every attendee must sign, a group session can sit partially signed while you wait on the last countersignature. Remind attendees to countersign so the package seals.

## Group size limits

Some state rules cap the number of supervisees in a group supervision session, or limit how much group supervision can count toward the requirement. AuditHalo evaluates these limits through the assigned rule and flags a gap if a session exceeds them. See [How state rules work](/docs/rules/how-state-rules-work).

> **Warning:** Adding more supervisees than a state rule allows for group supervision can make the session non-compliant for those supervisees. Check the rule's group limit before scheduling a large group.
