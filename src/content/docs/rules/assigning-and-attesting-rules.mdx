This guide covers two supervisor tasks: assigning a state rule to a supervisee and recording the attestations that rule requires. The rule sets the targets; attestations record the facts the rule cannot infer from logged hours, such as a filed contract or a completed training.

## Assign a rule

1. Open the supervisee detail page at `/dashboard/roster/[superviseeId]`.
2. Select **Assign rule**.
3. Choose the rule for the supervisee's state and license.
4. Set the **Obligation start** date, the day their supervised-hour clock begins.
5. Confirm with **Assign rule**.

The detail page now evaluates the supervisee against that rule and shows progress and gaps.

[Screenshot: the Assign rule form showing the rule selection and Obligation start date]

> **Note:** The obligation start date matters. It anchors duration windows and deadlines, so set it to the date the board recognizes, usually when the supervisee's registration took effect.

## Change a rule or its version

To move a supervisee to a corrected rule or a newer version, use **Change rule** on the rule summary. When AuditHalo publishes a newer version of the assigned rule, a banner offers the upgrade directly. See [Rule versions and drift](/docs/rules/rule-versions-and-drift).

## Record attestations

Some requirements are facts only the supervisor can confirm. AuditHalo surfaces these as attestation gaps. Common examples:

- A supervision contract filed with the board, with the filing date.
- A required supervisor training completed.
- Permit or registration dates.

To clear one:

1. On the detail page, find the attestation gap.
2. Record the attestation, entering the date (and hours, where the check asks for them).

The gap clears and the fact becomes part of the evidence record. If you record something in error, undo the attestation to remove it.

[Screenshot: an attestation gap on the detail page with the record-attestation control]

> **Warning:** An attestation is a statement of fact that goes into the audit trail. Record it only when the underlying event has actually happened, and use the correct date.
