This guide explains the Recovery Innovations (RI) Clinical Supervision Form: a structured form and PDF template that replaces the standard AuditHalo evidence package for organizations configured to use it. If your organization is not on the RI template, this article does not apply to you.

## When it applies

The RI form applies only to organizations whose PDF template is set to the Recovery Innovations template. For those organizations, supervision sessions use the RI Clinical Supervision Form instead of the standard evidence package. Every other organization uses the standard AuditHalo template and will not see the RI form.

## Completing the form

Supervisors complete the RI Clinical Supervision Form on the session's sign page before signing.

1. On the sign page at `/sign/[sessionId]`, open the clinical form section.
2. Set the supervision type and complete the form's required fields.
3. Save the form.
4. Sign the session.

See [Supervision types and the clinical form](/docs/sessions/supervision-types-and-clinical-form) for the supervision type field.

## What the sealed package contains

When an RI session seals, the saved form data is included in the evidence package and rendered into the RI Clinical Supervision Form PDF, a multi-page document that matches RI's required layout and carries the RI branding. The same signature and hash integrity applies as with the standard package. See [Understanding evidence packages](/docs/evidence/understanding-evidence-packages).

> **Note:** For RI organizations connected to Paycor, the sealed RI form is queued for delivery to the employee's Documents folder in Paycor. See [Connecting Paycor](/docs/integrations/connecting-paycor).
